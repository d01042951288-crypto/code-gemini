# 나만의 학습게임 만들기! 🎮

AI를 활용하여 초등학생들이 자신만의 학습 게임을 만들기 위한 맞춤형 프롬프트를 생성해주는 Streamlit 웹 애플리케이션입니다.

## 로컬에서 실행하는 방법
1. 필요 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. 앱 실행:
   ```bash
   streamlit run app.py
   ```

## GitHub 및 Streamlit Community Cloud 배포 방법
1. 이 폴더의 모든 파일(`app.py`, `requirements.txt`, `README.md`)을 여러분의 GitHub 리포지토리(Repository)에 업로드(Commit) 합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속하여 GitHub 계정으로 로그인합니다.
3. 우측 상단의 **'New app'** 버튼을 클릭합니다.
4. 방금 코드를 올린 GitHub 저장소, 브랜치(주로 `main` 또는 `master`), 그리고 Main file path에 `app.py`를 지정합니다.
5. **'Deploy'** 버튼을 누르면 몇 분 후 여러분만의 웹사이트 URL이 생성됩니다!
